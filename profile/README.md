## Overview
DroneDeploy for Windows is a desktop workspace connected to DroneDeploy's cloud mapping platform, built for construction, agriculture, and survey teams who need to see a site from above on a regular basis. Instead of handing over a memory card full of raw drone photos, the DroneDeploy app plans the flight and the cloud platform assembles what comes back into a single map or 3D model, ready to open on the desktop. Teams rely on it specifically because the same site gets flown more than once, and having every flight land in the same project makes it straightforward to see what's changed.

## Getting Started
The first session in DroneDeploy is normally spent setting up rather than flying: naming a project, marking out the boundary of the area that matters, and connecting a drone if one is on hand — though bringing in imagery captured earlier works just as well for a first look. From that point, each flight adds to the same project, and the desktop app becomes the place to open the resulting map, mark it up, and hand it off to whoever else needs to see it.

## FAQ
**What is DroneDeploy, exactly?**
DroneDeploy is a cloud-connected drone mapping platform; this Windows app is the desktop side of it, used for planning flights and reviewing the maps and models that come back from them.

**Does the DroneDeploy app cost anything?**
DroneDeploy is commercial, subscription-based software, with a free trial period available for new users.

**What Windows versions does it run on?**
It's built for recent 64-bit versions of Windows — DroneDeploy publishes its current requirements if you need to double check an older machine.

**Can I use imagery from a drone I already own?**
Yes — DroneDeploy is compatible with a wide range of drone platforms, and imagery can also be imported if it was captured separately.
